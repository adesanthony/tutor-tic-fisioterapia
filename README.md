# tutor-tic-fisioterapia
Tutor de estudio con IA para Tecnologías de la Información y la Comunicación, Fisioterapia 1.er nivel (UTA). Contenidos de las 4 unidades, talleres PAE 1 a 4, autoevaluación y fichas sobre comunicación, PEDro, Mendeley, Excel y contenidos multimedia. La IA funciona con la clave gratuita de Gemini de cada estudiante.
